1 Blacknight — Domain Registration

We only need the domain name momoslaser.ie. No hosting plan — the website runs free on GitHub.

What you need

  • 💳  Credit / debit card (~€15–25 once a year)

Create the account

  1. Go to blacknight.ie → click Sign Up
  2. Fill in your details — business name: Momo's Laser, Strokestown, Co. Roscommon
  3. In the search bar type momoslaser.ie → hit Search
  4. Click Add to cart
  5. When asked about hosting — skip / no thanks (domain only)
  6. Complete checkout with your card

Give Martin access

  1. Log in at blacknight.ie → go to My Account → Account Users
  2. Click Add User / Invite User
  3. Enter martinusko@gmail.com
  4. Set role: Administrator
  5. Save — Martin gets an email invitation

Martin can

  • Manage DNS settings
  • Renew the domain
  • Configure where it points

Martin cannot

  • See your billing details
  • Cancel the domain
  • Change account owner
⚠️ Risk Martin can change where the domain points. Since he's building the site this is necessary. You stay as account owner and the one being billed.

2 What Happens Next

MARTIN'S JOB — NOTHING NEEDED FROM YOU

Domain → Website

  1. Log into Blacknight and update DNS to point momoslaser.ie at GitHub
  2. Set the custom domain in the GitHub repository settings
  3. Enable HTTPS — free and automatic
After this, anyone visiting momoslaser.ie lands on the website.

Contact Form — EmailJS

  1. Create a free account at emailjs.com (200 emails/month free)
  2. Connect it to momoslaser@gmail.com — note the Service ID
  3. Create an email template using the form fields — note the Template ID
  4. Copy the Public Key from Account → API Keys
  5. Paste all three into contact.html and push to GitHub — form is live
